# 真实社交回复训练器

一个帮你在真实社交里「把话说明白、又不把关系搞僵」的练习小工具。

## 这个工具是干嘛的

它像一位随叫随到的沟通陪练，帮你练习那些不好开口的对话。

- 里面有 15 个常见真实场景（同事、工作、父母、朋友、社交、两性社交等）。
- 每个场景，你先写下自己会怎么回复。
- 写完后让 AI 给你打分，从四个方面评价：表达是否清楚、边界是否合适、语气是否自然、是否符合当时的情境。满分 100 分，并给出做得好在哪、可以怎么改。
- 它还会给你两种参考回复：一种温和但清晰，一种坚定直接；另外告诉你这个场景常见的误区，以及背后的沟通原则。
- 场景不够用可以自己加。新增时可以自己写，也可以选「AI 生成场景」，用一句话描述你想要的场景，AI 帮你把分类、标题、情景和参考回复一次生成好。
- 你加的场景和每次练习记录都会存在本机，下次打开还在。

## 为什么要有这个小工具

很多人在真实的社交里会卡住：不知道怎么拒绝别人，怕伤感情；想表达自己的需要，又怕显得自私或者太冲。这些能力在现实里练习的代价很高——说错一句话，可能得罪人、丢机会，甚至伤到亲近的关系。

这个小工具提供了一个没有后果的练习场：你可以先把自己的真实反应写出来，看看它够不够清楚、够不够尊重对方，再对照参考回复慢慢调整。它的目标是帮你把话讲清楚、把边界立住，同时不羞辱、不讨好、也不激化冲突，而不是教你憋着，或者教你硬刚。

## 怎么用

准备工作：

1. 电脑上装好 Python 3（Windows 安装时记得勾选 Add Python to PATH）。
2. 准备一个 DeepSeek 的密钥（在 DeepSeek 官网控制台创建）。AI 功能要联网，并且按用量产生费用。

使用步骤：

1. 双击 `social_reply_trainer.pyw` 打开程序。
2. 第一次使用，点右上角「API 设置」，把 DeepSeek 密钥填进去，保存。
3. 在左边场景库选一个场景；也可以点「＋ 新增训练场景」自己加一个。
4. 在练习区写下：如果是你，你会怎么回复。
5. 点「AI 评价我的回复」，等几秒，看分数和改进建议。
6. 点「查看参考回复」，对照温和版和坚定版的表达方式。
7. 点「练习记录」，可以回看之前每次练习的场景、你的回复和 AI 反馈。

新增场景有两种方式：自己填写分类、标题和情景；或者选「AI 生成场景」，只用一句话描述你想要的场景（比如「同事总把他的活推给我，我不想再忍了，又怕以后还要合作」），AI 会生成一个完整场景，你可以改一改再保存。

## 数据和隐私

- 所有数据都保存在程序文件夹下的 `data` 文件夹里，不会传到网上。
- `data` 里包括：`settings.json`（你的 API 密钥）、`custom_scenes.json`（自定义场景）、`scene_overrides.json`（对内置场景的修改）、`history.json`（练习记录）。
- `data` 文件夹已经被 `.gitignore` 忽略，不会上传到 GitHub。分享程序文件夹给别人前，记得先把 `data` 删掉。
- 不要把自己的 API 密钥写进代码，也不要发到聊天或截图里。

## 运行环境

- 只用 Python 自带的标准库，不需要额外安装 Python 包。
- 支持 Windows、macOS、Linux。
- AI 功能需要联网访问 DeepSeek。

## 文件说明

- `social_reply_trainer.pyw`：程序主文件，双击即可运行。
- `使用说明.txt`：面向使用者的说明。
- `AI_PROMPT.md`：程序发给 AI 的提示词说明。
- `data/`：本机数据（密钥、自定义场景、练习记录），不随仓库上传。
