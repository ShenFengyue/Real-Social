真实社交回复训练器 v2.5（AI增强版）

功能
- 内置 15 个社交训练场景。
- 可新增自定义情景，并通过 DeepSeek API 生成“温和但清晰”“坚定直接”两种回复，以及常见误区和沟通原则。
- 先针对情景写下自己的回应，再让 AI 从表达清晰、边界适当、语气自然和情境适配四方面评分并给出建议。
- 自定义情景会保存在本机，下次打开仍然存在。
- 场景库中的内置和自定义场景都可以编辑分类、标题、具体情景和额外要求，修改会保存在本机。
- 主界面采用场景库与练习工作区的双栏布局，以自主练习和 AI 反馈为主；参考回复与复制作为辅助功能。
- 仅使用 Python 标准库，无需安装额外 Python 包。

运行方法（Windows）
1. 安装 Python 3（安装时勾选 Add Python to PATH；多数情况下也可直接双击 .pyw）。
2. 解压 ZIP。
3. 双击 social_reply_trainer.pyw。
4. 首次使用 AI 功能，点击主界面右上角“API 设置”，填入你在 DeepSeek 控制台新建的 API 密钥，模型默认 deepseek-flash。
5. 选择一个情景，在练习区写下自己的回复，点击“AI 评价我的回复”获取分数和改进建议。
6. 点击“查看参考回复”对照不同表达方式；也可以从左侧场景栏新增自定义场景。

密钥安全
- 请不要把 API 密钥直接写进源码或分享给别人。
- 程序会把密钥保存在当前 Windows 用户配置目录：%APPDATA%\SocialReplyTrainer\settings.json。
- 该配置文件为本机普通文件，请不要把它上传、发给别人或放进公开仓库。
- 如果 API 密钥曾经发到聊天、截图或公开渠道，建议在 DeepSeek 控制台撤销并重新创建。
- AI 调用需要联网，且可能产生费用；请在 DeepSeek 控制台查看余额、限额和调用价格。
- 点击 AI 评分时，当前场景内容、额外要求和你写的回复会发送给 DeepSeek 进行分析；不要输入不希望发送到该服务的敏感信息。

本机数据位置
- API 设置：%APPDATA%\SocialReplyTrainer\settings.json
- 自定义场景：%APPDATA%\SocialReplyTrainer\custom_scenes.json
- 内置场景修改：%APPDATA%\SocialReplyTrainer\scene_overrides.json

排错
- 401：密钥无效、已撤销或填错。请新建密钥并重新保存。
- 402：账户余额或账户状态问题。
- 429：请求频率、额度或限速问题。
- 网络错误：确认网络可以访问 https://api.deepseek.com。

注意：这是一款社交沟通练习工具，AI 生成内容是建议而非保证正确的答案。涉及现实人身安全、权力差异或高风险冲突时，请结合具体环境谨慎判断。
